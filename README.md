# Image Processing Lab Assignments

This repository contains 10 Image Processing Lab assignments implemented using Python and Jupyter Notebook.

## Assignments

1. Grayscale to Binary Image Conversion
2. RGB to Grayscale Conversion
3. Image Padding and Complement
4. Image Enhancement
5. Image Smoothing
6. Histogram Processing
7. Image Sharpening
8. Noise Distributions
9. Local Binary Pattern (LBP) and Image Denoising
10. Adaptive Median Filtering and Otsu Thresholding

## Technologies Used

- Python
- Jupyter Notebook
- NumPy
- Matplotlib
- SciPy

## How to Run

1. Clone or download this repository.
2. Install the required Python libraries.
3. Open the notebooks using Jupyter Notebook or VS Code.
4. Run the cells to view the outputs.
